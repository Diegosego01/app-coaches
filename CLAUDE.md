# Instrucciones para Claude Code

Antes de trabajar en este proyecto, lee en este orden:

1. `CONTEXTO.md`: qué es la app, estado actual, decisiones y reglas de trabajo.
2. `README.md`: estado de cada fase.
3. `docs/`: un documento por fase (ficha de idea, descubrimiento, requisitos funcionales y no funcionales, marco legal).

Reglas:
- Seguimos el método de `docs/plantilla-proyecto-software.md`: una fase, un documento. No se escribe código hasta cerrar la documentación (arquitectura, stack y diseño de datos).
- Toda la documentación y la comunicación van en español.
- Lo que se asuma sin confirmar se marca como "Supuesto por confirmar".
- Al cambiar un requisito, actualiza también `CONTEXTO.md` y sube la versión del documento.
